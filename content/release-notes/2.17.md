This update has new features and improvements:

- Upcoming episode schedules are now shown on the List screen. You can also filter to only show anime that has an upcoming episode scheduled (useful to find shows that are currently airing or will start airing soon), and sort by next airing episode
- The List screen filter menu has a new "Set as Default" option, allowing filters to be applied automatically each time you launch the app. Anime and manga default filters are saved separately.
- The List screen's filter menu has been redesigned to reduce scrolling
- Added support for iPhone Duo
- Removed the "Open in Browser" option from share menus, since menus contain separate buttons to open on AniList now
